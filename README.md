# 🌐 Dilip's Portfolio

Welcome to my personal **Portfolio Website** — a modern and interactive React-based site where I showcase my skills, projects, and journey as a full-stack developer.

---

## 🚀 Live Demo

🔗 **[View Portfolio](https://portfolio1-ehew.onrender.com)**

---

## 🧭 Sections Overview

### 🏠 Hero

- Clean introduction with my name, role, and CTA buttons.

### 🙋‍♂️ About

- A short introduction about me — my goals, mindset, and learning path.

### ⚙️ Tech Stack

- Showcases my core technical skills.
- Smooth horizontal movement animation from right to left.
- Built using `react-icons` and `framer-motion`.

### 💼 Projects

- Displays my projects with live demo and GitHub links.
- Each card highlights what the project does and which tech stack I used.

### 📄 Resume

- Interactive resume viewer where users can:
  - Zoom In / Zoom Out / Reset
  - Navigate Next / Previous pages
  - Download the resume PDF
- PDF rendered using **react-pdf** for smooth control.

### 📬 Contact

- Users can send me a message directly.
- Both **the user and I receive an email confirmation** using **Nodemailer**.

### 🦶 Footer

- Includes copyright notice and social media handles.

---

## 🧰 Tech Stack

**Frontend:** React.js, Tailwind CSS, Framer Motion, React Icons  
**Backend (for mail):** Node.js, Express, Nodemailer  
**Other Tools:** Git, Render, Vercel, GitHub Pages

---

## 💡 Features

- Fully Responsive across devices
- Animated skill and section transitions
- Resume Viewer with interactive PDF controls
- Email system that auto-replies to users
- Clean and modern design
